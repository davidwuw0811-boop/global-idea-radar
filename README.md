## 这是什么

全球创意雷达站面向创业者、经营者和有行业资源的读者。这里不做“热门产品榜”，而是持续追问五件事：

1. 谁在什么场景遇到什么具体麻烦？
2. 产品真正改变了原流程的哪一步？
3. 谁使用、谁付钱，收费与经营证据到哪一层？
4. 现有替代是什么，优势能否持续？
5. 如果放到中国，哪些条件可以迁移，哪些必须重做？

GitHub 保存经核查的案例卡、公开来源、判断边界与后续修正；完整文章仍以网站审定稿为准，讨论入口以真实 X 原帖为准。

## 公开边界

- 事实、公司或创始人自报、第三方旁证、分析推断、尚未验证分开记录。
- Star、Fork、Issue 和流量不是收入、复购或付费意愿的替代指标。
- “值得写”不等于“值得投资”或“适合创业”；内容价值与经营成立分别判断。
- 待审稿、私人 Notion 任务、客户资料和未公开证据不进入本仓库。
- 网站或 X 尚未发布时，不编造链接，也不以占位 URL 冒充已发布。

## 更新节奏

- 周二速览发布后：同步当期摘要、入选案例卡与分类索引。
- 周五深拆发布后：更新同一案例卡，补反方、未知、核验日期与追踪记录；不另建重复案例。
- 重大事实纠错：在案例卡与 [CHANGELOG.md](CHANGELOG.md) 同时保留原判断和修正日期。
